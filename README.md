# 🛡️ Non-Functional Testing Playbook

A complete, free, interactive course on Non-Functional Testing — Performance,
Security, Usability, Accessibility, Reliability, Compatibility, Maintainability,
Portability, Compliance, and everything else that decides whether software survives
contact with the real world.

> 🚀 **Live demo:** <a href="https://ghanendra-sdet.github.io/non-functional-testing-playbook/" target="_blank" rel="noopener noreferrer">Open the interactive course</a>

Built the same way as its sister course, the
<a href="https://ghanendra-sdet.github.io/manual-testing-playbook/" target="_blank" rel="noopener noreferrer">Manual Testing Playbook</a>:
real examples grounded in real portfolio project case studies, not generic textbook
filler — plus dark mode, instant search, progress tracking, and zero build steps.

## What's covered

13 parts organized around **ISO/IEC 25010**, with **two full parts dedicated to
Security Testing** — the highest-blast-radius, most under-practiced discipline in most
QA careers:

1. NFT Fundamentals & ISO 25010
2. Performance Testing I — Load & Stress
3. Performance Testing II — Spike, Soak & Scalability
4. Security Testing I — OWASP & Fundamentals
5. Security Testing II — Penetration Testing & DevSecOps
6. Usability & Interaction Testing
7. Accessibility Testing
8. Compatibility Testing
9. Reliability, Availability & Recovery Testing
10. Maintainability & Portability Testing
11. Compliance, Privacy & Localization Testing
12. NFT Test Planning & Strategy
13. NFT in CI/CD, Chaos Engineering & Modern Trends

Full breakdown: [`00_Table_of_Contents.md`](00_Table_of_Contents.md)
